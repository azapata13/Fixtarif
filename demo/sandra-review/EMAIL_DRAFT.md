# Courriel a Sandra - brouillon

Objet : Fixtarif - version de demonstration et revue des documents

Bonjour Sandra,

La version de demonstration de Fixtarif est prete pour une premiere revue. Ce n'est pas encore une version finale ni un outil de production douaniere : les donnees et les documents sont fictifs, et chaque resultat doit etre valide par une personne.

Pour faire le test, connecte-toi a `https://app.fixtarif.ca/fr/login`, puis ouvre le tableau de bord. Le bouton **Preparer la demo** ajoute le scenario Canada `ST-DEMO-CA`; il permet de consulter le parcours et de generer un packing slip et un BOL brouillon. Le scenario `ST-DEMO-US` sert a regarder le flux de recherche et validation HTS.

Ce dont nous avons le plus besoin dans tes commentaires :

- les informations indispensables dans une vraie demande;
- les champs ou controles qui manquent dans les documents;
- les etapes qui devraient bloquer l'utilisateur ou seulement afficher un avertissement;
- la source officielle fiable que tu recommandes pour la recherche HS/HTS, avec les regles de revision et de mise a jour.

Nous avons aussi prepare un petit questionnaire technique pour la future source HS/HTS afin d'integrer les bonnes donnees sans presenter une suggestion comme une decision douaniere.

Merci beaucoup, tes commentaires vont directement guider la prochaine version.

Felipe
